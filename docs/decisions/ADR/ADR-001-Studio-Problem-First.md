# ADR-001: Problem First Approach

Date: 2026-08-05

Status: Accepted

---

# Context

Many technology initiatives start with a technology capability and then search for a problem to solve.

The Studio rejects this approach.

The purpose of the Studio is not to create technology for its own sake.

The purpose is to identify valuable real-world problems and develop solutions that create measurable value.

---

# Decision

The Studio adopts a Problem First approach.

Every initiative must begin with:

- A real-world signal
- A meaningful problem
- A clear opportunity

Technology selection happens after understanding the problem.

---

# Principle

The Studio follows this flow:
Reality

↓

Problem

↓

Research

↓

Solution

↓

Validation

↓

Product

↓

Value


---

# Consequences

Positive:

- Reduces technology-driven projects without value
- Focuses resources on meaningful opportunities
- Improves product-market alignment

Negative:

- Requires more research before engineering
- Some ideas may be rejected before development

---

# Future Impact

All future Studio systems, AI workers, and operating processes should follow this principle.

Problem discovery is the entry point of the Studio.
